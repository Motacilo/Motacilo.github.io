プライバシーポリシー

はじめに

Motacilo（以下「当サイト」）は、利用者のプライバシー保護に努めます。 本プライバシーポリシーは、当サイト（motacilo.com / motacilo.github.io）および 当サイトからリンクする Motacilo のサービス全般における情報の取り扱いについて説明するものです。

1. 運営者

当サイトは個人により運営されています。 お問い合わせは各 SNS（YouTube、X、note 等）からご連絡ください。

2. 当サイトで扱う情報

2-1. アクセス解析（Google Analytics 4）

当サイトおよび当サイト上の Web アプリ（例：なんとなく作曲）では、 利用状況の把握とサイト改善のため、 Google Analytics 4（GA4） を使用しています。 Google により、以下のような情報が収集される場合があります。

  • 閲覧したページの URL
  • 参照元（どのサイトから来たか）
  • ブラウザ・OS・画面サイズなどの端末情報
  • おおよその地域（IP アドレスから推定）
  • 利用日時

これらは Google のプライバシーポリシーに基づき処理されます。 詳細は Google プライバシーポリシー をご確認ください。

GA4 の利用に伴い、Google が Cookie 等を使用する場合があります。 無効化する方法は Google アナリティクス オプトアウト アドオン をご参照ください。

2-2. Cookie について

当サイトでは、上記 GA4 によるアクセス解析のために Cookie が使用される場合があります。 当サイト自体は、Cookie を使った広告配信や行動ターゲティング広告は行っていません。

ブラウザの設定で Cookie を無効にすることもできますが、 一部の機能や他サイトでの表示に影響する場合があります。

2-3. お問い合わせ時の情報

SNS 等でお問い合わせいただいた際に、ご提供いただいた内容（メッセージ、ユーザー名等）を お問い合わせ対応のために利用します。

2-4. Web アプリのローカル保存（localStorage）

当サイト上の一部 Web アプリでは、利用者のデータを運営者のサーバに送信せず、 お使いのブラウザ内の localStorage（または sessionStorage）にのみ保存する機能があります。

なんとなく作曲（雰囲気メロディ）（ motacilo.com/mathematical-music/ ）では、作曲中の下書き、お気に入りにした候補、保存した譜面を localStorage に保存します。 個人を特定する情報やアカウント登録は行いません。

ブラウザのデータを削除すると、これらの保存内容も消えます。 都道府県点描クイズなど、他のアプリについては各サービスのプライバシーポリシーもご確認ください。

3. 情報の利用目的

収集した情報は、以下の目的で利用します。

  • サイトおよびアプリの改善・機能向上
  • 利用状況の分析（どのコンテンツ・導線が利用されているかの把握）
  • お問い合わせへの対応

4. 広告について

当サイトでは、現時点で第三者の広告配信は行っていません。 将来導入する場合は、本ポリシーを更新します。

5. 第三者への提供

法令に基づく場合を除き、利用者の個人情報を第三者に販売・提供することはありません。 アクセス解析のため Google にデータが送信される点については、上記「2-1」をご覧ください。

6. 外部リンク

当サイトからリンクする外部サイト（YouTube、Google Play、各 Web アプリ、SNS 等）には、 それぞれ独自のプライバシーポリシーが適用されます。 各サービスのポリシーもご確認ください。

7. 各アプリ・サービスについて

当サイトからリンクしている個別のアプリ・Web サービスには、それぞれ独自のデータ取り扱いがあります。 詳細は各サービスのプライバシーポリシーをご確認ください。

  • なんとなく作曲（雰囲気メロディ） — 下書き・お気に入り・譜面は localStorage にのみ保存（上記「2-4」）。 アクセス解析に GA4 を使用（上記「2-1」）。
  • 都道府県点描クイズ — 各サービス内のプライバシーポリシーをご確認ください。

8. 改定について

本プライバシーポリシーは、法令の改正やサービス内容の変更に伴い、必要に応じて改定することがあります。 重要な変更がある場合は、本ページの更新日を変更してお知らせします。
